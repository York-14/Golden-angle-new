# Golden Angle Phyllotaxis — Breathing

黄金角（golden angle, 約137.5°）を使ったフィロタキシス（葉序）パターンのアニメーションです。p5.js を用いた単一の HTML ファイルとして実装しています。

## モデルの概要

- **golden angle 配置**: 各要素を `theta = i * 137.50776...°`、`r = c * sqrt(i)` で配置し、ひまわりの種のような螺旋パターンを生成します。
- **花弁形状**: 各点に楕円（花弁）を配置し、中心からの角度に沿って回転させることで放射状の花のような見た目にしています。
- **呼吸アニメーション**: 各花弁に `scale(t_anim)` を適用し、時間とともに拡大・縮小を繰り返す「呼吸」のような動きを表現しています。中心からのインデックスに応じて位相をずらすことで、外側に向かって波打つような視覚効果を生んでいます。
- **スライダー**:
  - `elong` — 花弁の伸び（楕円の長軸方向の伸縮率）
  - `A` — 呼吸アニメーションの振幅
  - `f` — 呼吸アニメーションの速さ（周波数）

## ローカルで動かす方法

このリポジトリをクローンまたはダウンロードし、`index.html` をブラウザで直接開くだけで動作します（ビルドやサーバー起動は不要です）。

```bash
git clone https://github.com/York-14/Golden-angle-new.git
cd Golden-angle-new
open index.html   # macOS の場合。Windows/Linux ではブラウザで index.html をダブルクリック
```
