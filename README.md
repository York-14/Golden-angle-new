# Golden Angle Phyllotaxis — Breathing

黄金角（golden angle, 約137.5°）を使ったフィロタキシス（葉序）パターンのアニメーションです。p5.js を用いた単一の HTML ファイルとして実装しています。2D版と3D版（Fibonacciスフィア）の両方を収録しています。

## モデルの概要

### 3D版（`index.html`） — Fibonacciスフィア

- **配置**: 球面上に均等に螺旋分布させる Fibonacci sphere（Vogelモデルの3D拡張）を使用。方位角に golden angle（`theta = i * 137.50776...°`）を使い、`y` を球の極から極まで均等ステップで動かして極角を決めることで、球面上に隙間なく螺旋状の点群を生成します。
- **花弁形状**: 各点に3D球（楕円体）を配置し、中心から各点への半径方向に長軸を向けています。
- **呼吸アニメーション**: 2D版と同じく `scale(t_anim)` による拡大縮小と、インデックスに応じた位相ずらしで波打つ動きを表現。
- **操作**: マウス/タッチのドラッグでカメラを自由に回転できます（p5.js `orbitControl`）。
- 2D版へのリンクは画面右下にあります。

### 2D版（`2d.html`）

- **golden angle 配置**: 各要素を `theta = i * 137.50776...°`、`r = c * sqrt(i)` で配置し、ひまわりの種のような螺旋パターンを生成します。
- **花弁形状**: 各点に楕円（花弁）を配置し、中心からの角度に沿って回転させることで放射状の花のような見た目にしています。
- **呼吸アニメーション**: 各花弁に `scale(t_anim)` を適用し、時間とともに拡大・縮小を繰り返す「呼吸」のような動きを表現しています。中心からのインデックスに応じて位相をずらすことで、外側に向かって波打つような視覚効果を生んでいます。

両バージョン共通のスライダー:
- `elong` — 花弁の伸び（長軸方向の伸縮率）
- `A` — 呼吸アニメーションの振幅
- `f` — 呼吸アニメーションの速さ（周波数）

## ローカルで動かす方法

このリポジトリをクローンまたはダウンロードし、`index.html`（3D版）または `2d.html`（2D版）をブラウザで直接開くだけで動作します（ビルドやサーバー起動は不要です）。

```bash
git clone https://github.com/York-14/Golden-angle-new.git
cd Golden-angle-new
open index.html   # macOS の場合。Windows/Linux ではブラウザで index.html をダブルクリック
```
